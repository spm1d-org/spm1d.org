Support

  • Questions, discussion and feature requests: the spm1d forum (see Forum and private support)
  • Bug reports: the issue tracker of the package you are using (see Bug reports and Bug report guidelines)
  • Email support is unavailable; if you have questions please use the spm1d forum

Bug reports

If spm1d produces an error or a result you believe is wrong, please open an issue in the repository of the version you are using, with a minimal example that reproduces it:

  • spm1d 0.4 (Python): spm1d-v0.4/issues
  • spm1d 0.4 (MATLAB): spm1d-matlab-v0.4/issues
  • rft1d: rft1d/issues
  • power1d: power1d/issues
  • registration1d: registration1d/issues

Bug report guidelines

Acceptable bug reports include:

  • an unexpected error: an error that spm1d does not raise deliberately. Errors raised deliberately, with a message that explains how to avoid them, are not bugs.
  • an unexpected warning: a warning that does not signal documented behavior.
  • an unexpected result: you can prove that an spm1d output, error or warning is demonstrably wrong.

Before submitting a bug report please:

  • Read Questions that are not bug reports
  • Prepare your report following Before opening an issue
  • Assemble your report following What a bug report must contain and What a bug report must NOT contain

Questions that are not bug reports

The following types of questions are good but they are not bugs. They should be submitted to the spm1d forum:

  • How to properly use spm1d procedures
  • What an spm1d procedure’s arguments mean
  • What spm1d procedures are suitable for a particular experimental design
  • How to prepare your data
  • How to interpret or report spm1d results
  • How spm1d relates to statistics procedures like: power, sample size, multiple comparisons corrections, etc.
  • Requests to look at a dataset or an analysis script
  • etc.

Before opening an issue

  1. Check that you are on the current version.
  2. Search the existing bug reports (both open and closed) for similar reports.
  3. Reduce the problem. Remove everything from your script that is unnecessary to reproduce the problem. A minimal, reproducible example will help the spm1d team to solve the problem quickly. If you go through the process of simplifying a script you may also discover the source of the problem.

What a bug report must contain

A bug must be reproducible. A report therefore requires all of the following:

  • A minimal example that runs. The example must be complete, self-contained and as short as possible. Do not attach your own data; use a built-in dataset or create random data that represent the problematic features of your dataset.
  • What you expected to happen and why.
  • What actually happened: spm1d outputs and/or figures. If an unexpected error or warning was produced then copy the full error/warning and paste as text into the bug report.
  • One problem per issue. Two problems should be submitted as separate issues.
  • Configuration details: the versions of spm1d, Python, NumPy, SciPy and Matplotlib, and your operating system.

Template

#### What I did

```python
import numpy as np
import rft1d
import spm1d

np.random.seed(0)
y    = rft1d.randn1d(8, 101, 20)
spmi = spm1d.stats.ttest(y).inference(0.05)
print( spmi )
```

What a bug report must NOT contain

  • Data. A report that can only be reproduced with a specific dataset is a report that hasn’t been thoroughly considered. If the problem depends on some property of your data (for example a constant column, a missing value or a particular sample size), say so and reproduce that property with random numbers.
  • Unnecessary commands. Include only commands that are necessary to reproduce the bug. A 200-line script with the problem somewhere inside it is a request to debug your script and is not a bug report.
  • Screenshots of text. Copy-and-paste output / error / warning text if relevant. Figure screenshots or renderings are fine.
  • Multiple problems. Open a separate issue for each problem you encounter.

Feature requests

Please submit feature requests to the spm1d forum. Describe what you want to do and/or the feature. Please do not submit requests for non-Python support (MATLAB, R, etc.).
