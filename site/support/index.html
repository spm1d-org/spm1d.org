Bug reports

If any spm1d.org package produces an error, warning or a result you believe is wrong, please report it along with a minimal example that reproduces it.

Before submitting a bug report please read the bug report guidelines.

  • spm1d 0.5 (Python): spm1d-v0.5/issues
  • spm1d 0.4 (Python): spm1d-v0.4/issues
  • spm1d 0.4 (MATLAB): spm1d-matlab-v0.4/issues
  • rft1d: rft1d/issues
  • power1d: power1d/issues
  • registration1d: registration1d/issues

Bug report guidelines

Acceptable bug reports include:

  • an unexpected error: an error that an spm1d.org package does not raise deliberately. Errors raised deliberately, with a message that explains how to avoid them, are not bugs.
  • an unexpected warning: a warning that does not signal documented behavior.
  • an unexpected result: you can prove that an spm1d output, error or warning is incorrect.

Copy-and-paste output text if relevant. Do not take screenshots of text.

Figure screenshots or renderings are fine.

Before opening a bug report

  1. Check that you are on the current version.
  2. Search existing bug reports (both open and closed) for similar reports.
  3. Create a minimal reproducible example. The example must be complete, self-contained and as short as possible. Do not attach your own data; instead use a built-in dataset or create random data that represent the problem.

Configuration details

When opening a bug issue you will be prompted for configuration information. Configuration information can be obtained from all spm1d.org packages using:

<package>.get_config()

For example:

spm1d.get_config()

Feature requests

Please submit feature requests using the Feature request form in the issue tracker of the relevant package (New issue → Feature request). Describe what you want to do and/or the feature. Please do not submit requests for non-Python support (MATLAB, R, etc.).

Private support

Support subscribers to spm1d.org receive a private GitHub repository in order to ask questions directly to the spm1d.org development team. Subscribers also receive access to the spm1d knowledge base where they can search through our growing set of documents and conversations regarding statistics, programming and all other matters related to spm1d.
